# Python Data Analytics Portfolio
**Author:** Rutvik Chaudhari
**Focus:** Algorithmic Data Processing, Aggregation, and Reporting

## Project 1: Sales Report Generator
- **Objective:** Extract raw text data from CSV, perform integer type-casting, apply comparative logic to aggregate maximum values, and automate a text-based analytical report.
- **Language:** Python (Pure Logic / Standard Library)
- **Status:** Complete

## Project 2: Automated Data Cleaning Pipeline
- **Objective:** Deduplicate raw datasets, impute missing (`NaN`) values using statistical mean, and compute validated totals.
- **Language:** Python (Pandas)
- **Status:** Complete

## Project 3: Regional Profitability & BI Aggregation
- **Objective:** Engineer profit margins from raw sales data, group metrics by region (`groupby`), rank by profitability, and export automated CSV reports.
- **Language:** Python (Pandas)
- **Status:** Complete

## Project 4: Regional Profit Visualization
- **Objective:** Ingest local CSV data and generate publication-ready bar charts (`regional_profit_chart.png`).
- **Tools:** Python (Pandas, Matplotlib)
- **Status:** Complete

## Project 5: Embedded SQL Analytics
- **Objective:** Load datasets into an in-memory SQLite database and execute filtered `SELECT` / `ORDER BY` queries.
- **Tools:** Python (SQLite3, Pandas)
- **Status:** Complete

## Project 6: Z-Score Anomaly Detection
- **Objective:** Calculate mean, standard deviation, and Z-scores to mathematically isolate statistical outliers ($|Z| > 2$).
- **Tools:** Python (Pandas)
- **Status:** Complete

## Project 7: Linear Regression Revenue Forecasting
- **Objective:** Compute Pearson correlation ($r$) and fit an Ordinary Least Squares ($y = mx + b$) model to forecast revenue from ad spend.
- **Tools:** Python (NumPy, Pandas)
- **Status:** Complete

## Project 8: Relational Table Merge & Segmentation
- **Objective:** Perform SQL-equivalent `INNER JOIN` operations (`pd.merge`) across normalized tables and aggregate revenue by customer tier.
- **Tools:** Python (Pandas)
- **Status:** Complete
